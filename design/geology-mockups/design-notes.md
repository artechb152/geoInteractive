# Geology mockups

Three visual proposals based on Computer Use review of live Topic 01 and Topic 03.

1. Opening: two explanatory regions around one terrain cutaway.
2. Rocks: a specimen gallery with a selected-family information dock.
3. Forces: internal and external processes around one mountain, plus a summary band.

Images generated with the built-in image-generation tool. Prompts: prompts.json.
Rock photos are illustrative placeholders for the user-created photos. Copy was shortened for mockup readability. This is a design proposal; no live website or application styles were changed.

Palette follows existing cream, olive, pine, tan and orange tokens. Desktop RTL composition. Site shell is indicative; final implementation should retain the existing navigation and use left-pointing forward arrows. Small generated text and specimen accuracy require review before production use.
