## מה הלומד עושה

כרטיס לבן אחד. המפה בצד שמאל (סוף השורה), והשלב הנוכחי בצד ימין: כותרת, הוראה קצרה, פעולה אחת ומשוב.

| שלב | פעולה | מה קורה |
|---|---|---|
| 1 הדגמה (א) | „הפכו את הכיוון” | נמדד ‎080°‎ אל מגדל המים. הקו משורטט מהמגדל ב־‎080°‎, ומנקודה עליו המגדל נראה ב־‎260°‎, לא כמו במדידה. |
| 1 הדגמה (ב) | „לתרגול” | הקו ההפוך ‎260°‎ (‎080° + 180°‎). משלוש נקודות על הקו המגדל נראה ב־‎080°‎. קו אחד לא מספיק. |
| 2 בחירה | בחירת שני עצמים, במפה או בכפתורים, ואז „מדידה במצפן” | הבחירה מסומנת בטבעת ניטרלית. בחירה שלישית מחליפה את הראשונה. |
| 3 קווים | הקלדת האזימוט החוזר לכל עצם (‏↑↓ מסובבים במעלה), ואז „בדיקה” | הקו במפה זז בזמן ההקלדה, בצבע ניטרלי. אחרי הבדיקה הקו מסומן כנכון או כשגוי. |
| 4 מיקום | לחיצה על המפה, או חיצים ו־Enter | סימון ניטרלי עד הבדיקה. |

„התחלה מחדש” מחזירה את התרחיש הנוכחי לשלב הבחירה. בזמן ההדגמה היא מחזירה לתחילת ההדגמה.

## מודל גאומטרי אחד

המודל כולו ב־`navigationSimModel.ts`, ללא React. המפה, המדידות, הקווים, הבדיקות והפתרונות נגזרים ממנו. הרכיב שמצייר את המפה לא מקבל את המיקום הנכון כקלט, ולכן לא יכול להציג אותו לפני הלומד.

- גיליון בדיוני של ‎2,400 × 1,800‎ מ׳, צפון למעלה. כל אזימוט נמדד מצפון המפה, וגם המצפן בתרגיל מכוון לאותו צפון. הערה מתחת למפה אומרת זאת.
- העצמים נבנו כחיתוך של שתי קרניים במעלות שלמות, מתרחישים A ו־B. לכן כל המדידות בשני התרחישים האלה מדויקות. את מיקום C מצאתי בחיפוש: שלוש המדידות ממנו רחוקות פחות מ־‎0.02°‎ ממעלה שלמה, ולכן הקו מחטיא את המיקום בפחות מחצי מטר.

| תרחיש | מגדל המים | אנטנה | פסגה 412 | חיתוך הקווים הצר ביותר |
|---|---|---|---|---|
| A | ‎056° → 236°‎ | ‎284° → 104°‎ | ‎190° → 010°‎ (חוצה את ‎0°/360°‎) | ‎46°‎ |
| B | ‎013° → 193°‎ | ‎304° → 124°‎ | ‎238° → 058°‎ | ‎45°‎ |
| C | ‎046° → 226°‎ | ‎337° → 157°‎ | ‎113° → 293°‎ | ‎44°‎ |

- ההדגמה משתמשת בקו ‎080°/260°‎ ממגדל המים. הקו הזה רחוק לפחות 150 מ׳ מכל מיקום של תרגול, ונוטה ממנו לפחות ‎15°‎.
- המיקומים רחוקים לפחות 150 מ׳ מכל דרך, מהערוץ ומהגבעות, כדי שלא יהיה אפשר לנחש אותם מסימן במפה.
- סימון נחשב נכון עד 60 מ׳ מהמיקום, כ־16 פיקסלים ב־1440. קו נחשב נכון רק בהתאמה מלאה של מעלות שלמות, כי המדידות אידאליות.

## חיבור ללשונית התרגול בפרויקט הראשי

קובץ אחד: `src/app/lessons/[topicId]/page.tsx`, עם סופי שורה CRLF. ב־2026-10-27 הקובץ זהה ל־HEAD.

**1. ייבוא.** מיד אחרי `import { Topic12Lesson } from '@/components/lessons/topic-12/Topic12Lesson';`:


**2. מפת תרגולים.** מיד לפני `export function generateStaticParams() {`:

```tsx
// A lesson's own practice, where it has one; the others keep the placeholder.
const customPractice: Record<string, () => React.ReactNode> = {
  'topic-06': () => <NavigationSim />,
};
```

**3. הלשונית.** החליפו:

```tsx
      practice={<InteractionPlaceholder kind={lesson.interactions[0]} />}
```

ב:

```tsx
      practice={customPractice[topicId] ? customPractice[topicId]() : <InteractionPlaceholder kind={lesson.interactions[0]} />}
```

**4. בדיקה** מהתיקייה הראשית:


## החלטות הדרכתיות: הצעות לבדיקה שלכם (לא אושרו)

1. **ההדגמה מתחילה בטעות.** קודם מוצג קו ‎080°‎ מהמגדל, ומנקודה עליו המגדל נראה ב־‎260°‎. אחר כך מוצג הקו ההפוך. הניגוד נועד להסביר למה הופכים. החלופה: להציג רק את הקו הנכון.
2. **מקלידים את הקו, לא גוררים אותו.** החישוב הוא מטרת הלמידה, וגרירה הייתה מזמינה לכוון לפי העין. ‏↑↓ מסובבים במעלה. אפשר להוסיף גרירה במפה בהמשך.
3. **שתי בדיקות נפרדות:** קודם הקווים ואחר כך הסימון, כדי שכל משוב יעסוק בטעות אחת. החלופה: בדיקה אחת בסוף, שבה הלומד רואה לאן קווים שגויים מובילים.
4. **קרן מהעצם, לא קו שלם דרכו.** כך גם טעות של כיוון לא הפוך נראית במפה: הקו בורח מהאזור.
5. **כל זוג עצמים מתאים, ואין משוב על הבחירה.** בכל הזוגות זווית החיתוך היא ‎44°‎ לפחות. אפשר להוסיף זוג עם חיתוך צר, כדי ללמד לבחור עצמים בהפרש של כ־‎90°‎.
6. **העצם השלישי.** הלומד מחשב גם את הקו שלו. הבדיקה היא התאמה מלאה של הערך, והמשוב מנוסח כ„עובר או לא עובר דרך הסימון”.
7. **עזרה מדורגת.** רמז 1 אחרי בדיקה שגויה, ורמז 2 עם החישוב והתוצאה פתוחה. הפתרון מוצע אחרי רמז או אחרי שתי טעויות. העזרה נסגרת אחרי תשובה נכונה.
8. **סבילות:** 60 מ׳ לסימון, והתאמה במעלה שלמה לקו.
9. **סגירה:** רצועה של ‎±2°‎ סביב כל קו, ומספר אחד. בתרחיש A, למשל: קו של כ־1,000 מ׳ זז בכ־35 מ׳ ליד המיקום.
10. **שלושה תרחישים במחזור** (A → B → C → A). „תרחיש נוסף” מופיע רק בסיום.
11. **פורמט מדידות:** תלת־ספרתי (‎056°‎). מקבלים ‎56‎, ‏‎360‎ נקרא כ־‎0‎, וערך מעל 360 מקבל הנחיה בלי ציון נכון או שגוי.
12. **צבעים:** הבחירה והקו הפעיל בכתום, שהוא צבע הפעולה באתר. ירוק ואדום מופיעים רק אחרי בדיקה.
