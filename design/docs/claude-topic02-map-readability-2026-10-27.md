# פרומפט — קריאות מפת קווי הגובה והסרת הפרעה במדידה

טפל בשני פגמי קריאות ממוקדים בשיעור 2, בלי לשנות את המעטפת או את רוחב השיעור ובלי commit. קרא AGENTS.md, design/docs/lesson-screen-guide.md ואת ממצאים ב4, ב5 וג7 ב־design/docs/topic02-independent-user-audit.md. עבוד על המצב העדכני ושמור שינויים של אחרים.

אחריות: מסך המודל הראשון ב־ContoursScene.tsx ורכיב המפה המקומי שלו לפי הצורך; ובתיקיית scale/ רק התנהגות רמז הזום ומיקומו. אל תשנה את מסך צפיפות קווי הגובה, את המודל התלת־ממדי, את שאר מפות השיעור, את נתוני התרגול או את המעטפת המשותפת.

1. במפת קווי הגובה הראשונה נמדדו ערכי גובה בגודל כ־9px וסרגל קנה מידה כ־7.5px אחרי ההקטנה. בנוסף, ״50״ חופף ליחידה ״מ׳״. מדוד מחדש ב־1440×1122. הגדל את המפה במרחב הזמין ואת התוויות המקומיות לפי הצורך, כך שהמספרים, היחידות והצפון קריאים על המסך עצמו. יעד מינימום לתוויות נתונים הוא כ־12px בפועל, בלי הקטנת טקסט אחר ובלי לנפח את הכרטיס מעבר למסך.
2. שמור על יחס הממדים, הגאומטריה, הצפון, הקשר למודל ועל הסנכרון של שכבה מודגשת בעכבר ובמקלדת. שמור את שלוש התצוגות, הגרירה והאיפוס. אל תשנה גבהים או קנה מידה מקצועי כדי לפנות מקום לטקסט. ודא שכל תווית נשארת במקום הנכון ושהגדלתה אינה יוצרת חפיפות.
3. בקנה מידה, רמז הזום נשאר מעל אזור המדידה עד שמשתמשים בזום. בטל את ההפרעה במעבר למדידה או בתחילת פעולה במפה, ושמור דרך להבין שאפשר להתקרב בלי לכסות נקודה או סרגל. אל תשנה את החישובים, הסמנים, התקריב או אופן גרירת המפה.

לפני שינוי קובץ משותף בדוק מי משתמש בו. העדף שינוי מקומי או אפשרות מוגדרת כדי לא לשנות פעילויות אחרות. אין צורך בסריקה ותיקון גורפים של כל תוויות SVG בפרויקט במשימה הזאת.

בדוק בדפדפן ב־1440×1122: שלוש תצוגות קווי הגובה; הדגשת שכבות מהמפה ומהמודל; מקלדת; טעינה; תקריב אם קיים; מדידה של נקודה אחת ושתי נקודות; החלפת קנה מידה; זום וגרירה. ודא שאין חפיפות, חיתוך או חריגה מהמסך. מדוד את גודל התוויות אחרי scale ולא רק את font-size בקוד.

החזר צילומי לפני/אחרי, מידות התוויות בפועל ותוצאות הבדיקות. אל תבצע build בתיקייה הראשית; פעל לפי docs/dev-environment.md. תעד במסמך מסירה ייעודי.
