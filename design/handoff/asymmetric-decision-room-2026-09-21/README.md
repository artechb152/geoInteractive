# חבילת תכנון — פעילות הזמן בשיעור 1

גרסה עדכנית: [גרסה 3 — חמש זירות עם מעברי מסך](../asymmetric-smooth-film-v3/README.md). היא מחליפה את התמונות, ההנפשות ופרומפט קלוד בחבילה זו. תמונה 3 החדשה ללא אזכרה.

עדכון התמונות: [גרסה 2 — חמש זירות מובחנות](IMAGE-PROMPTS-V2.md) מחליפה את פרומפטי התמונות להלן. פרומפטי ההנפשה והכיוון החזותי בפרומפט קלוד המקורי מתייחסים עדיין לחדר הקבוע, ולכן אינם תואמים לגרסת התמונות החדשה.

נוצרה ב־21.09.2026. קובצי תכנון בלבד; לא נערך קוד האתר ולא הופקה מדיה.

הכיוון המוצע: חדר החלטות אחד, מצלמה קבועה וארבעה לחצים שמצטברים סביב החזית הצבאית. חמש תחנות, חמישה פריימים, ארבע הנפשות. הלומד שולט בזמן באמצעות האקורדיונים וציר הזמן.

- [חבילת Google Flow המלאה](GOOGLE-FLOW-PROMPTS.md): ההיגיון הלימודי, טבלת הפריימים, סדר הפקה, חמישה פרומפטים מלאים לתמונות וארבעה פרומפטים מלאים להנפשה.
- [פרומפט הפיתוח לקלוד](CLAUDE-PROMPT.md): תוכן, התנהגות, רכיבים קיימים, סקילים, נכסים ובדיקות.
- image-prompts/: כל אחד מחמשת פרומפטי התמונות בקובץ טקסט נפרד.
- motion-prompts/: כל אחד מארבעת פרומפטי ההנפשה בקובץ טקסט נפרד.

אין צורך להוסיף לפרומפטים בקובצי הטקסט הוראות בסיס מקובץ אחר — כל אחד שלם בפני עצמו. בהפקת התמונות F02–F05 עדיין חייבים לצרף את הפריים הקודם כרפרנס, ובהנפשות חייבים לצרף את זוג פריימי ההתחלה והסיום.
