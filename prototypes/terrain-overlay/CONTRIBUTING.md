# תרומה לפרויקט

## לפני שמתחילים

[`ROADMAP.md`](ROADMAP.md) הוא **מקור האמת היחיד למצב הפרויקט**. כל שינוי בקוד מלווה
בעדכון המסמך, וההוראות המדויקות נמצאות בראשו. משימה שאינה מופיעה שם — הוסיפו אותה
לקטגוריה המתאימה לפי גודלה ולפי סדר הדחיפות.

## סביבת עבודה

```bash
nvm use          # Node 20, לפי .nvmrc
npm install      # מתקין גם hook של pre-commit שמריץ lint-staged
npm run dev
```

## לפני כל commit

```bash
npm run verify   # טיפוסים + ESLint + Prettier + בדיקות + תקציב נכסים
```

זהו בדיוק מה שרץ ב-CI. אם זה עובר מקומית, זה יעבור שם.

## שלושה כללים שחוסכים את רוב התקלות

### 1. אין לערוך את `src/data/` ביד

הספרייה כולה נוצרת אוטומטית. שלושת מקורות האמת הם:

| מה                   | איפה                                              |
| -------------------- | ------------------------------------------------- |
| גאוגרפיה של האזורים  | `tools/areas.config.json`                         |
| **כל** הטקסט הלימודי | `content/terrain.he.json`                         |
| כל הגאומטריה         | מודל הגובה עצמו, דרך `tools/extract-features.mjs` |

עריכה ישירה ב-`src/data/` תימחק בהרצה הבאה של הצנרת, בלי אזהרה.

### 2. פיסוק עברי תקני

גרש `׳` (U+05F3) וגרשיים `״` (U+05F4) — **לא** אפוסטרוף לטיני. כלומר `מ׳` ו-`תצ״א`.
בדיקה אוטומטית נכשלת אחרת.

מספרים בסביבה דו-כיוונית עוטפים ב-`<Num>` או `<Range>` מ-`lib/format.tsx`. טווח כמו
`287–539` בתוך פסקה RTL מתהפך ל-`539–287` בלי בידוד, וזה נראה רק בעין.

### 3. משתני תבנית — הכול או כלום

`{interval}`, `{cliffPct}` וכדומה מוצבים בזמן הבנייה. **אם משתנה אחד חסר לאזור
מסוים, כל המחרוזת מושמטת בשקט.** לפני שמוסיפים משתנה לטקסט של צורה, ודאו
ש-`tools/extract-features.mjs` באמת מייצר אותו לכל אזור שבו הצורה מופיעה.

מותר להשתמש במשתנים ב-`localNote` וב-`challenge.answer` בלבד.

## הוספת צורת שטח

1. **גלאי** ב-`tools/lib/landforms.mjs`. הוא חייב להחזיר `null` כשהקריטריון אינו
   מתקיים — צורה מזויפת גרועה בהרבה מצורה חסרה, כי הלומד לומד ממנה דבר שגוי.
   הספים צריכים להיות קרטוגרפיים ומתועדים, ורצוי נמדדים (ראו `findBasin`).
2. **חיווט** ב-`tools/extract-features.mjs`, כולל הוספה למערך `order`.
3. **תרשים חתימה** ב-`ContourSignature.tsx` והרחבת `SignatureKind`.
4. **תוכן** ב-`content/terrain.he.json` תחת `kinds`.
5. **בדיקה**: הוסיפו את המזהה ל-`REQUIRED_KINDS` ב-`tests/data.test.ts`.

## אימות חזותי

הגאומטריה והפריסה הם נתונים שקטים: נתיב שנשבר או תווית שזזה עוברים גם קומפילציה
וגם בדיקות יחידה, ונראים רק בעין.

```bash
npm run build && npm run preview &
node tools/verify/shots-l05.mjs   # כל 16 הצורות בכל 8 האזורים
node tools/verify/shots-l07.mjs   # מצבי השוואה, שיעור, חתך גובה
```

שני הסקריפטים נכשלים על שגיאת קונסול ועל אזור לחיצה שחורג מה-viewBox.

## סגנון קוד

- הערות בעברית, ומסבירות **למה** ולא **מה**. הערה ששוות-ערך לשם הפונקציה מיותרת;
  הערה שמסבירה איזה באג הקוד מונע — שווה זהב. אם מספר נבחר אחרי מדידה, כתבו מה נמדד.
- Prettier מכריע בכל שאלת עיצוב. אל תתווכחו איתו.
- `src/data/`, `dist-lib/` ו-`ROADMAP.md` מוחרגים מ-Prettier בכוונה.
