## [Unreleased]

### נוסף

- **מצבי השוואה** — וילון נגרר (ברירת מחדל), זה-לצד-זה מסונכרן, ושכבת הצללה
  (hillshade) שנגזרת ממודל הגובה. בורר מצב תצוגה בסרגל הפקדים. (L-07)
- **מעקב התקדמות וחיבור למערכת הלמידה** — שמירת מצב מלאה, מחוון "נצפו X מתוך Y",
  קישורים עמוקים (`#area=…&feature=…&mode=…`), `onProgress` / `onComplete`,
  ושכבת xAPI אופציונלית. (L-06)
- **מסלול שיעור מובנה** — מבוא, חקירה מונחית, תרגול, מבחן וסיכום. (L-10)
- **כלי חתך גובה** — סימון קו על המפה פותח גרף חתך, עם קישור דו-כיווני בין
  הגרף למפה. (L-11)
- **כלי עריכת תוכן** (`?editor=1`) — ציור `hitPath`, קביעת `labelPoint`
  ו-`flowArrow`, וייצוא JSON. (L-12)
- **הקראה קולית** — Web Speech API בעברית עם בקרת מהירות. (M-16)
- **תשתית בדיקות** — Vitest, בדיקות תקינות נתונים, Playwright e2e, axe-core,
  ESLint, Prettier ו-CI. (L-08, S-14)
- **אריזה כספרייה** — `vite build --lib`, API של props, ותשתית i18n. (L-09)
- ספריית צורות מורחבת ל-16 צורות. (L-05)
- קיצורי מקלדת מלאים עם חלונית תיעוד. (S-15)
- קבצי תשתית: `LICENSE`, `CHANGELOG.md`, `.editorconfig`, `.nvmrc`,
  `CONTRIBUTING.md`. (S-18)

### שונה

- ברירת המחדל של ההשוואה היא **וילון** ולא שקיפות 50% — במצב האמצע שתי השכבות
  היו בלתי קריאות. (L-07)
- `README.md` נכתב מחדש כתיעוד מוצר: props, מבנה נתונים, הוספת אזור ורישוי. (S-17)

### תוקן

- טיפוגרפיה עברית: גרש/גרשיים תקניים, `lang`/`dir` על קטעים לועזיים,
  ומספרים בסביבה דו-כיוונית. (S-16)
- נקודות הגילוי מקבלות משוב חזותי ונעלמות אחרי שהצורה נצפתה. (S-22)

## [0.1.0] — 2026-08-15

הגרסה הראשונה שיצאה מכלל פרוטוטייפ.

### נוסף

- מנוע רב-אזורי עם 7 אזורי לימוד שכל הגאומטריה שלהם מחולצת ממודל גובה
  אמיתי. (L-01)
- מנוע תרגול ומבחן בשלושה מצבי משחק, עם ניקוד, רצף, רמזים וחזרה ממוקדת. (L-02)
- זום 1×–6×, הזזה ולופה. (L-03)
- נגישות מלאה של המפה: ניווט מקלדת, `aria-label` לכל צורה, ותיאור
  `sr-only`. (L-04)
- מילון מונחים אינטראקטיבי, השוואה בין אזורים, דף עזר, ומסך סיכום.
- אופטימיזציית נכסים: AVIF/WebP, `srcset`, LQIP ותקציב של 400KB לאזור. (M-04)
