## Adopted decisions

### 2026-09-15 — Lesson 1 (topic-01) speaks one design language

Full rationale and the list of rulings: `design/docs/assumptions.md` → "2026-09-15 — Topic-01 whole-lesson design-language unification". Adopted as lesson-wide (and, where the component is shared, course-wide) rules:

- **One content width.** Every scene root is `max-w-lesson mx-auto px-4 sm:px-6 lg:px-8`; no per-block negative-margin breakouts. The overview page, the practice/check tabpanel, the learn-tab pager and the lesson-nav footer are capped to the same width. Measured: every scene root x=40 w=1152 at 1440px.
- **One vertical rhythm.** SceneHeader → first block 32px; every block after that 48px (`mt-12`).
